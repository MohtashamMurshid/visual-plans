Visual
components.

Drop-in charts and diagrams for plan pages. Include /components.js, pass JSON in a data attribute, and each element renders as an SVG in the house style.

Bar chart.

<vp-bar-chart>

<vp-bar-chart label="Fraud signals by source"
  data='[{"label":"Risk signals","value":670,"display":"670+","highlight":true}, …]'>
</vp-bar-chart>

Line chart.

<vp-line-chart>

<vp-line-chart label="Deploy time per release"
  data='{"points":[42,38,31,33,24,19,14],"labels":["v1","v2",…],"unit":"s"}'>
</vp-line-chart>

Donut & progress.

<vp-donut> · <vp-progress>

<vp-donut data='{"value":80,"display":"80%","caption":"complete"}'></vp-donut>
